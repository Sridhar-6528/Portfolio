# Sridhar S — Personal Portfolio

Personal portfolio website built with **React**, **React-Bootstrap**, **Bootstrap 5 (Dark Theme)**, and **Vite**, based on the academic profile, projects, research, and certifications of **Sridhar S** (M.Sc Software Systems, Kongu Engineering College).

## Highlights

- **Hero & Resume Download**: Profile portrait, concise overview, and direct download of the resume PDF (`public/Sridhar_S_Resume.pdf`).
- **About & Education**: Academic timeline (`M.Sc Software Systems`, `HSC`, `SSLC`) and engineering interests.
- **Technical Skills**: Interactive React-Bootstrap pill filters covering Programming Languages, Web & Databases, Cloud & DevOps, and Testing & Research.
- **Featured Projects & R&D Focus**: Dedicated breakdown and interactive workflow selector for **An Incremental Learning Framework for Parkinson's Disease Classification Using Multimodal Analysis** (MRI & DaTSCAN SPECT), alongside AWS/Terraform automation and Sign Language Translator projects.
- **Certifications & Contact**: Verified credentials, LeetCode profile link, one-click copy contact cards, and a React-Bootstrap email composition form.

## Run Locally

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Build for production:
   ```bash
   npm run build
   ```
4. Preview the production build:
   ```bash
   npm run preview
   ```
